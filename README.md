# Influenza-Like Illness (ILI) Data Analysis

## Overview
Exploratory data analysis of influenza-like illness, weather, and pollen datasets across 15 cities.

## Objectives
- Clean and preprocess multiple datasets.
- Handle missing values, duplicates, and inconsistent data.
- Merge weather, pollen, and ILI information.
- Analyze seasonal patterns and potential relationships.
- Create visualizations to communicate findings.

## Dataset
- 27,000+ records
- 15 cities
- Weather measurements
- Tree, grass, and weed pollen data
- Influenza-like illness data

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

- Data preprocessing
- Dataset merging
